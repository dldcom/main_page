# 🎮 풍성한 수업을 위한 에듀 게임 포털 (Edu Game Portal)

학생들이 학교 수업에서 다루는 다양한 학년별/과목별 학습 게임에 쉽게 접근하고 즐길 수 있도록 모아둔 **통합 게임 포털 웹페이지**입니다. 
누구나 접속하여 한눈에 게임을 찾아보고 플레이할 수 있도록 직관적인 UI를 제공합니다.

---

## ✨ 주요 기능 및 특징

1. **트렌디한 네오 브루탈리즘(Neo-brutalism) 디자인**
   - 굵은 테두리와 짙은 그림자, 원색의 생동감 넘치는 색상을 사용하여 학생들의 흥미를 유발하는 힙하고 감각적인 디자인을 적용했습니다.
2. **맞춤형 필터링 시스템**
   - **학년/학기 필터**: '공통', '4학년' 등 학년별로 게임을 분류해서 볼 수 있습니다.
   - **과목 필터**: '국어', '과학', '창체' 등 원하는 과목의 게임만 쏙쏙 골라볼 수 있습니다.
3. **모바일 / 태블릿 완벽 대응 (반응형)**
   - 학생들이 주로 사용하는 태블릿 환경에 최적화되어 있습니다.
   - 주소창이나 하단 스와이프 바에 UI가 가려지지 않도록 `viewport-fit=cover`, `100dvh` 및 `env(safe-area-inset)`가 적용되어 화면을 넓고 쾌적하게 사용할 수 있습니다.
4. **이미지 자동 압축 지원**
   - 게임 썸네일 용량을 최소화(WebP)하여 로딩 속도를 극대화할 수 있는 압축 스크립트(`convert.js`)가 포함되어 있습니다.

---

## 📂 프로젝트 구조

```text
📦 main_page
 ┣ 📂 images/          # 압축된 게임 썸네일 (WebP 포맷)이 저장되는 폴더
 ┣ 📜 index.html       # 웹페이지 구조 및 레이아웃
 ┣ 📜 style.css        # 네오 브루탈리즘 디자인 및 반응형 스타일 시트
 ┣ 📜 app.js           # 게임 데이터베이스 및 필터링/렌더링 자바스크립트 로직
 ┗ 📜 convert.js       # PNG/JPG 이미지를 WebP로 자동 압축 변환해주는 Node.js 스크립트
```

---

## 🚀 새로운 게임 추가하는 방법

1. **게임 썸네일 준비하기**
   - 추가할 게임의 스크린샷 파일(`.png` 또는 `.jpg`)을 `main_page` 폴더에 넣습니다. (예: `newgame.png`)
   
2. **썸네일 이미지 최적화 (WebP 압축)**
   - 터미널을 열고 아래 명령어를 실행하여 이미지를 압축합니다.
   ```bash
   node convert.js
   ```
   - 스크립트가 원본 이미지를 압축하여 `images/` 폴더 안에 최적화된 `.webp` 파일로 저장합니다.

3. **데이터베이스에 게임 등록하기**
   - `app.js` 파일을 열고 최상단의 `const games = [...]` 배열 안에 아래 양식으로 게임 정보를 추가합니다.
   ```javascript
   { 
       titleInfo: { term: '학년/학기', subject: '과목', unit: '단원명', name: '게임 제목' },
       description: '게임에 대한 간단한 설명',
       url: 'https://게임주소.xyz', 
       grade: '학년 필터 (예: 전체, 4학년)', 
       subject: '과목 필터 (예: 창체, 국어)', 
       type: '분류', 
       bgColor: '#ff90e8', // 카드 기본 배경색 설정
       image: 'images/압축된파일명.webp' // 생성된 썸네일 경로
   }
   ```
4. 파일을 저장하고 웹페이지를 새로고침하면 새로운 게임이 포털에 나타납니다!

## ⚙️ 실행 및 배포 환경

- 별도의 백엔드 서버가 필요 없는 **순수 정적 웹사이트(Static Website)**입니다.
- GitHub Pages, Cloudflare Pages, Vercel 등 정적 웹 호스팅 서비스에 폴더를 그대로 업로드하면 즉시 배포되어 작동합니다.
- 로컬 환경에서 테스트할 경우 `index.html` 파일을 브라우저로 직접 열거나, VSCode의 Live Server 확장 프로그램을 사용하여 확인할 수 있습니다.
