WHO WE BUILD FOR

게임을 찾은 다음,
수업으로 연결하는 일.

대상 사용자는 한국의 초등교사입니다. 교사가 학습 게임을 선택한 뒤, 해당 단원의 목표에 맞는 활동 안내와 확인 문항을 준비하는 과정을 돕고자 합니다.

현재는 12개의 웹 학습 게임을 학년·과목별로 탐색하고 실행할 수 있습니다. 앞으로는 같은 흐름 안에서 수업자료 초안까지 준비할 수 있도록 확장할 계획입니다. 교사의 현장 관점과 이미 공개한 학습 도구를 출발점으로 삼습니다.

FROM CLASSROOM TOOL TO EDUCATION SERVICE

게임을 넘어, 교사를 위한 수업 설계 서비스로.

서비스 개발 · 사업화 계획

게임을 찾은 뒤에도 교사는 활동 안내, 수준별 질문, 정답과 해설을 준비해야 합니다. DLDCOM은 이 과정을 하나의 흐름으로 연결해 교사가 초안을 검토하고 수업에 맞게 다듬는 시간을 돕고자 합니다.

01 / BUILD

수업자료 초안 도구

게임의 학습 주제, 학년, 학습목표를 바탕으로 활동 안내와 기초·적용·확장 질문, 정답·해설을 준비하는 기능을 개발합니다.

02 / VALIDATE

교사와 함께 검증

교과 내용의 정확성, 학년별 난이도, 수정에 드는 시간을 확인합니다. 현장 피드백을 통해 유용성과 유료 이용 의향을 검증할 계획입니다.

03 / SUSTAIN

구독과 학교 이용권

검증 후 개별 교사 구독과 학교 단위 이용권을 목표로 합니다. 가격·판매 조건은 아직 정하지 않았으며, 현재 유료 서비스는 출시 전입니다.

2026년 5월 시작한 독립 프로젝트입니다. 사업자등록·법인 설립 전이며, 위 내용은 향후 개발과 사업화 목표입니다.

WHAT WE PLAN TO BUILD WITH CLAUDE

학습 내용에 맞는 초안,
교사의 검토로 완성.

개발 계획 · Claude API 연동 전

Claude API로 선택한 게임의 학습 주제와 교사가 입력한 학년·학습목표에 맞춰 확인 문항, 정답·해설, 활동 안내 초안을 생성하는 기능을 개발할 계획입니다.

생성 결과는 교사가 수정하고 확인한 뒤 수업자료로 사용하도록 설계합니다. 현재 제공되는 게임은 AI 없이 실행됩니다. 개발에는 OpenAI 도구를 활용하고 있으며, 수업자료 생성 기능은 앞으로 Claude API 연동을 검증해 구현할 계획입니다. 현재 Claude 연동과 생성 기능은 구현 전입니다.

PRODUCT OVERVIEW

From learning games
to teacher-reviewed materials.

DLDCOM is an independent educational software project for Korean elementary school teachers, developed by an elementary school teacher in South Korea. Started in May 2026, it currently offers 12 browser-based learning games and simulations organized by grade and subject. Teaching materials from the portal have been shared on Indischool, a Korean teacher community, and used by teachers. The source code and development history are publicly available on GitHub.

Our next development goal is to help teachers turn a learning game into lesson materials. We plan to integrate Claude API to draft questions, answer explanations, and activity instructions based on a selected game's topic and teacher-specified grade and learning objectives. Teachers would review and edit the drafts before classroom use.

Cloudflare reported 5.49k Unique Visitors and 379.57k Total Requests across the dldcom.xyz domain over September 8–October 8, 2026, based on an owner-provided dashboard screenshot. These are domain traffic metrics, potentially including automated traffic and resource requests, not verified human users or teacher counts. Owner-provided Indischool comments from June 25–26 express positive feedback on shared teaching materials and intent to use them; they are not validation of an AI feature.

The current games work without AI integration. OpenAI tools are used in development; integrating Claude into the planned lesson-design service is a future goal. The AI feature is not yet implemented. After teacher testing, we aim to offer individual subscriptions and school licenses. This is an unincorporated, not yet business-registered project; paid offerings have not launched.
